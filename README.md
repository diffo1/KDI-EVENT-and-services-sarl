# KDI Enterprise Platform

Enterprise Event Management, ERP, CRM and Client Portal.

## Technology Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Next.js 15
- React 19
- Tailwind CSS
- Redis
- Docker
- GitHub Actions

## Repository Structure

- apps/api – Backend API
- apps/website – Public website
- apps/admin – Administration dashboard
- apps/client-portal – Customer portal

## Quick Start

```bash
cp .env.example .env
docker compose up --build
```
